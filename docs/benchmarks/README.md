# Измерения Ферма

На публичном ключе `20261002_231554_public.key` с модулем 16 383 бита выполнены два
коротких последовательных запуска оптимизированного алгоритма. Каждый имел общий бюджет 5 секунд.
Это локальные замеры на данной машине, без гарантии повторения скорости при другой нагрузке.

| Режим | Кандидатов | Кандидатов/с | Активные потоки | Средняя занятость CPU рабочих потоков |
|---|---:|---:|---:|---:|
| [1 поток](rsa-20261002-205044-219-1threads.txt) | 201 103 | 40 632 | 1/1 | 0,9947 ядра |
| [16 потоков](rsa-20261002-205115-889-16threads.txt) | 2 341 656 | 473 227 | 16/16 | 14,45 ядра |

Ускорение между этими короткими запусками — примерно 11,6 раза. Оба используют один и тот же
фильтр квадратных остатков и динамические блоки; разница — число рабочих потоков.
Из 2 341 656 кандидатов параллельного запуска квадратный корень вычислялся для 74 350.
Остальные кандидаты исключены точной проверкой остатков по модулю 4032.

[Первоначальный отчет](rsa-20261002-original-single-thread.txt) сохранен отдельно:
он относится к предыдущей реализации в один поток без фильтра остатков и бюджету 170 секунд.
В нем было проверено 226 108 кандидатов при скорости около 1 330 кандидатов/с.

Полный запуск обновленного теста с отдельным замером Ферма на 180 секунд и всеми процессорами
(плюс резерв на подготовку и сохранение отчета):

```bash
./gradlew rsaKeyAttackTest -PrsaPublicKey=Keys/20261002_231554_public.key --console=plain
```

Для пяти минут добавьте `-PrsaAttackSeconds=300`. Допустимо 1–3600 секунд;
тайм-ауты JUnit и Gradle увеличиваются вместе с бюджетом (на 20 и 30 секунд соответственно).

Сохранён [результат запуска на 300 секунд](rsa-20261002-213830-490-16threads.txt):
146 594 797 кандидатов, около 488 644 кандидатов/с, 16/16 активных потоков и
средняя занятость 14,82 ядра. Замер Ферма занял 300,003 секунды, весь эксперимент —
300,074 секунды; сообщение не восстановлено. Это результат одного запуска, а не
доказательство криптостойкости ключа.

Быстрый запуск или выбор потоков:

```bash
./gradlew rsaKeyAttackTest -PrsaPublicKey=Keys/20261002_231554_public.key -PrsaAttackSeconds=5
./gradlew rsaKeyAttackTest -PrsaPublicKey=Keys/20261002_231554_public.key -PrsaAttackThreads=1 -PrsaAttackSeconds=5
```

Новые отчеты получают имя с временем UTC и числом потоков. Последний отчет также доступен
в [rsa-key-benchmark-latest.txt](../rsa-key-benchmark-latest.txt). В него входят точные счетчики,
скорость, условная экстраполяция в годах и время проверки известного сообщения публичным ключом.
Оценка в годах относится к условному полному диапазону Ферма, а не к фактическому времени взлома RSA.
